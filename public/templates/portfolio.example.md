# 私人持仓清单（模板 · 请另存为自己的副本）

> 这个文件只是模板，**不要把自己的真实数字写进仓库里的这个文件**。  
> 复制一份到你自己的目录（例如 `~/Documents/my-portfolio.md` 或 iCloud 备忘录），填好后在 App 的「我的 → 导入清单文件」里导入。
>
> 导入后数据只存在**这台设备的浏览器本地**（localStorage），不会上传到 GitHub、也不会同步给任何人。  
> 换设备或清理浏览器数据前，先在「我的 → 导出完整备份」保存 JSON。

## 怎么填

- 每行一只股票/ETF，`代码` 必须是 6 位数字。
- `状态` 填 `持仓` / `自选` / `历史`（也接受 holding / watch / history）。
- `股数`、`成本`、`历史收益` 可以留空；持仓股建议填股数与成本，这样 App 才能算保护位与参考股数。
- 行首的 `goldValueCny: 金额` 是黄金产品的参考市值（可选，只用于展示）。
- 表头行可以保留，解析时会自动跳过。

## 导入方式

1. 打开 App（本地 http://localhost:3000 或线上 https://treymodels.github.io/kate-intraday/）
2. 进入「我的」页
3. 点「导入清单文件」，选择这份 `.md`（也支持 `.json` / `.txt` / 内含 `stocks.md` 的 `.zip`）
4. 导入只**新增**股票，不会覆盖已有记录；重复代码会跳过
5. 之后每次打开 App 会自动读取本设备已保存的清单，不用重复导入
