# 使用说明（盘中版）

面向「我现在该不该买 / 什么时候卖」这个问题的本地看板。所有数据在本机浏览器里计算，不上传、不连券商、不自动下单。

## 打开

```bash
cd kate-dashboard
PATH=/opt/homebrew/bin:$PATH npm run dev
# 浏览器打开 http://localhost:3000
```

iPhone 上打开同一地址，Safari 分享 → 添加到主屏幕，可当 PWA 用。

## 页面怎么读

**顶部状态条**：相位（盘前 / 集合竞价 / 交易中 / 午休 / 已收盘 / 非交易日）、最近报价时间、数据年龄、成功/失败/订阅数、自动刷新开关。

**股票清单行情**：公开 29 只的当前价与规则动作（回踩低吸 / 突破跟随 / 持有 / 逢高减仓 / 优先止损 / 等待信号）。

**今日优先清单**（你自己的清单）：每张卡给出现价和三个价位——

| 标记 | 含义 | 怎么用 |
|---|---|---|
| 触发 | 到了这个价才考虑买 | 收盘后看，次日开盘挂条件单；不追高 |
| 保护 | 跌破就止损 | 持仓者跌破必须走，不摊低成本 |
| 目标 | 到这里分批止盈 | 到价先减一部分，剩余跟趋势 |

卡片还显示「距触发 +x%」——离买点还有多远；负值表示已经越过触发价。

**盘中提醒**：命中触发 / 止损 / 目标时，这里出一条（同时弹浏览器通知、可选提示音）。同一只票同一类当天只提醒一次。

## 加自己的股票

「股票」页 → 右上「添加股票」→ 输入 6 位代码与名称 → 保存 → 点「更新」。

会自动拉日线（东财 → JSONP → 腾讯回退，本机实测腾讯可用）。拉到后策略卡就会给出上面的三个价位。

## 提醒怎么开

提醒面板 →「开启浏览器通知」→ 浏览器允许。iOS 需要先添加到主屏幕；声音可能被浏览器自动播放策略拦截，站内提醒始终兜底。

关掉「自动刷新」时，提醒暂停（避免后台刷屏）；点「刷新报价」可手动拉一次。

## 时段行为

| 时段 | 行为 |
|---|---|
| 盘前（<09:15） | 显示上一交易日收盘价，标「盘前」，不提醒 |
| 集合竞价（09:15–09:25） | 尝试报价；若数据源时间戳未更新，会明确提示 |
| 交易中（09:30–11:30 / 13:00–15:00） | 每 15 秒刷新，命中即提醒 |
| 午休（11:30–13:00） | 停更，标「午休」，不提醒 |
| 收盘后（>15:00） | 显示收盘价，标「收盘」，不提醒 |

## 数据与限制

- 本机出网 IP 被东方财富反爬，报价走腾讯 `qt.gtimg.cn` 回退；日线走腾讯 `fqkline` 回退。回退路径不返回成交额，`amount=0`。
- **法定节假日未识别**，按工作日处理；节假日拉不到当日数据会明确报错，不会拿旧值冒充。
- 公开清单只覆盖 29 只，不是全市场扫描；规则分数不是收益概率。
- 回测语义：收盘出信号、次日开盘执行，已计入单边 0.10% 成本、防止未来函数。

## 常见提示

- **「上次报价 HH:mm:ss」**：本轮刷新失败，显示的是上一笔真实报价，不是实时。
- **「可能延迟」**：报价超过 2 分钟没更新。
- **「暂无报告」**：本地没有 `public/data/latest.json` 快照。正式使用应让定时任务生成；本地开发可放一份快照文件。
- **「失败 N 只」**：这些代码本轮没拿到报价，原因在错误行里列出。

## 不构成投资建议

策略是固定规则的研究结果，不保证收益，不连接券商，不自动下单。
