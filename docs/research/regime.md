**指标口径**（便于复核）：
- MA20/60/120 = 收盘价的简单移动平均（对最近 N 个交易日收盘）。
- 20/60/120 日涨跌 = `close_t / close_{t-N} − 1`，N 为交易日数。
- ATR14 = 最近 14 个交易日真实波幅 TR 的简单平均（非 Wilder 递推），`TR = max(H−L, |H−C_{t-1}|, |L−C_{t-1}|)`；ATR14/价 = ATR14 ÷ 收盘价。
- 距 250 日高 = `close_t / max(high, 最近250个交易日) − 1`。
- 20/60 量比 = 最近 20 日平均成交量 ÷ 最近 60 日平均成交量（腾讯指数成交量口径，**不可与全市场成交额直接换算**）。
- MA60 斜率 = `MA60_t / MA60_{t-20} − 1`。

**合成**：

```
指数均分 indexAvg = 6 个指数 (T1..T5 之和) 的平均      ∈ [−5, +5]
宽度均分 breadthAvg = (B1+B2+B3)/3                      ∈ [−1, +1]
综合评分 composite = 0.7 × indexAvg + 0.3 × breadthAvg   ∈ [−3.8, +3.8]

状态判定：
  Bull  : composite ≥ +1.5  且 breadthAvg > 0（宽度同向）
  Bear  : composite ≤ −1.5  且 breadthAvg < 0（宽度同向）
  Range : 其余情况

置信度：
  High   : 一致率 ≥ 85% 且 |composite| ≥ 2.5
  Medium : 一致率 ≥ 70% 或 |composite| ≥ 1.5
  Low    : 其余
  一致率 = 与 composite 同向的检查项数 / 33 项（6×5 + 3）
```
