# 私人持仓：只在你这台设备上（不上 GitHub）

这份说明回答两件事：**持仓文件放在哪、怎么进 App、怎么保证不跑到 GitHub 上**。

## 一句话版本

你把持仓写在一个本地 Markdown 文件里 → 在 App 里导入一次 → 数据只存在**这台设备这个浏览器**（localStorage）→ 之后每次打开自动载入 → 不上传、不同步、仓库里也没有。

## 三种东西，别混淆

| 东西 | 在哪 | 会不会上 GitHub |
|---|---|---|
| 持仓文件（你自己填的 `.md`） | 你的电脑/手机本地 | **不会**（App 不读它、也不上传；只有你点「导入」时浏览器读一次） |
| 导入后的持仓数据 | 当前浏览器 localStorage | **不会**（没有任何上传代码路径；公开站点只提供静态页面） |
| 公开清单快照 `public/data/latest.json` | 仓库 + 线上静态文件 | 会，但它只有 29 只公开代码的行情/信号，**不含任何私人数据** |

## 操作流程

1. **下载模板**：App「今日」页空状态或「我的」页 → 下载模板（也可直接打开 `public/templates/portfolio.example.md`）
2. **填好并存到本地**：建议放在仓库目录之外，例如 `~/Documents/my-portfolio.md`；iCloud/备忘录也行（注意隐私）
3. **导入**：App「我的」→「导入清单文件」→ 选这份 `.md`
   - 只新增，不覆盖已有记录；重复代码跳过
   - 支持 `.md` / `.json` / `.txt` / 内含 `stocks.md` 的 `.zip`
4. **自动加载**：以后打开 App 自动读取本设备数据，不用重复导入
5. **备份/换设备**：「我的」→「导出完整备份」得到 JSON，在新设备「导入备份」

## 为什么会「只有这台设备」

App 是纯静态页面，所有计算在浏览器里完成；持仓存在 `localStorage`，按站点域名隔离：

- 本机开发地址（`http://localhost:3000`）和线上地址（`https://treymodels.github.io/kate-intraday/`）是**两个不同的存储空间**，数据不互通；
- 换浏览器、换手机、清理网站数据 → 数据消失，必须重新导入备份；
- 同一台电脑同一浏览器 → 一直在。

## 防止误提交到 GitHub

仓库 `.gitignore` 已经屏蔽常见命名：`portfolio*.md`、`holdings*.md`、`positions*.md`、`stocks.md`、`*.private.md`、`private/`。
但这只是保险，**最稳的做法是把真实文件放在仓库目录之外**，永远不要 `git add` 它。

如果你已经在仓库目录里放了真实文件，可以确认它没有被跟踪：

```bash
git status --short          # 不应出现你的持仓文件
git check-ignore -v 我的持仓.md   # 若被忽略会打印规则
```

## 安全边界

- App 不连接券商、不下单、不把持仓发给任何第三方；行情请求只带股票代码，不带股数/成本。
- 浏览器通知权限、声音是本地能力，不涉及数据上传。
- 导出的 Markdown 含私人财务信息，别发到公开聊天/公开云链接。

## 已知限制

- localStorage 不是加密存储；同一台电脑上其他能开这个浏览器的人可以看到（与任何本地网页应用相同）。
- 清理浏览器数据/无痕模式会丢数据；重要数字请定期导出 JSON 备份。
- 线上站点是公开的静态页面，任何人可打开看**公开清单**，但看不到你的持仓（持仓只在你的浏览器里）。
